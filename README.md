# Muhammad Hamza — Portfolio Website

My personal portfolio: **https://mhamza6051.github.io**

Plain HTML/CSS/JS (no build step), hosted free on GitHub Pages from this repository.
Showcases my AI / ML / Deep Learning projects with links to every GitHub repository.

- `style.css` — vibrant dark theme, animated gradient orbs, reveal-on-scroll, hover effects
- `script.js` — project category filters, scroll reveal, animated counters, typing effect
- `img/` — AI-generated banner images for the four featured projects
